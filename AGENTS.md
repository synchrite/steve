# Working in this repo

Steve's Day Off: a single-file pixel-art game (`index.html`) plus art in `assets/`.

- **Codex:** you do the art. Follow `CODEX.md` exactly (16-bit target, sizes, palette, anchors, originality rules).
- **Claude:** does the game code, wiring new assets in, and gameplay changes.
- Never edit `frozen/`. It is a locked earlier version.
- `ref/` holds the owner's reference photos. It is local only and ignored by git; never commit it.
- `git pull --rebase` before you start and before you push. Small commits, one asset or one change each.
- Questions for the owner go at the bottom of `CODEX.md` under "Notes from Codex".
